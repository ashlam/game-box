怎么玩

Windows 里那个最经典的纸牌。把四个花色各自从 A 收到 K，全部收满就赢。

1认牌桌

牌堆：点一下翻牌 4 个收牌堆 7 列牌

左上那叠扣着的牌是牌堆，点它就翻到旁边；翻完可以再把整叠收回来重翻。右上 4 个格子是收牌堆，收进去的牌就不用管了。

2怎么摆牌

列里大的在下、小的在上，而且颜色要一红一黑交替。一叠牌只要连着降序 + 红黑交替，就能整段一起搬。

3怎么收牌

收牌堆只认同一花色、正好大一位的牌：A 才能起头，之后 2、3 一路到 K。桌上看见能收的，连点两下就送上去。

4怎么操作

👆点左上牌堆翻牌，翻完再点就把整叠收回来重翻
✋按住牌直接拖到目标上松手；拖不动会自己飞回去
👆也可以点一张牌 → 再点目标位置，两种都行
👆连点两下同一张牌 = 直接送进收牌堆
⚡底下「收牌」把现在能收的一次收干净
↩走错了就撤销，可以一直退回去

5分数怎么算

送牌进收牌堆 +10
翻出一张扣着的牌 +5
从收牌堆把牌拿回牌桌 −15
牌堆翻完了、整叠收回来重翻 −20

分数只进不退到 0 以下，翻 1 张和翻 3 张各记各的最高分。
