怎么玩

数织 · Nonogram · Picross · 像素拼图

数字 = 一段有几格 · 左边 1 1 2，上面 3 1 0（0 = 整列空）

数字 = 这一行连续黑格的长度，从左到右按顺序。列的数字从上面开始。

  • 3 → 这行有一段 3 连
  • 2 1 → 先 2 连，中间至少空一格，再来 1 个
  • 0 → 这行整行是空的

用手指直接划就能连着一片涂完；划歪了也没关系，它会沿直线走。在已经涂色的格子上再划一遍，就是擦掉。

拿不准的地方用 ✕ 标成空格，省得反复数。整行填对了，那行数字会自己变暗。填错会闪红并计数；卡住了点右下角 💡。
