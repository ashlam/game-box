玩法（照着公园那台实机做的）

  1. 开局给 200 枚代币。
  2. 点「投币口」投币，一次 1 枚（按住会连投）。本局至少投 5 枚， 最多 20 枚。
  3. 投够了按「开始」——随机抽一个倍数（2x / 4x / 6x / 8x / 10x）， 然后随机点亮出口的灯。倍数越低，亮的出口越多。
  4. 按住「拉扳机」蓄力，松手把弹珠射出去。蓄力越大球飞得越远，落点越靠左。
  5. 球落进亮灯的出口 → 返还 投注 × 倍数 的代币。
  6. 落进没亮灯的出口 → 本局投注不退。本局结束，重新投币开下一局。
