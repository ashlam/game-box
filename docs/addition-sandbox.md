# 加法沙盘 v2 · 从「演示」改成「循环」

> v1 的问题：四个机制全是**放映**。他改不了任何东西，于是没有期待、没有悬念，
> 屏幕上只剩「图形在动」—— 那就是抽象。
>
> v2 只回答一个问题：**什么样的表现形式，能同时承载「他控制 → 他押注 → 画面揭晓机制」这个循环？**
>
> 新原型：`tools/proto/hand-sum.html`（旧的四页原型 `addition-lab.html` 仅作对照保留）

---

## 1. 上一版到底错在哪

不是画得不够好，是三处结构性错误：

**错误一：全是放映，没有输入。**
他只能看。一个不能被改变的画面，对孩子来说不是"工具"，是"电视"。
没有输入就没有期待，没有期待就没有悬念，最后只剩下"有个东西在动"。

**错误二：动画全部自动开演。**
这一条最致命。**悬念在时间上就是一段留白** —— 需要他盯着屏幕、心里过一下"会是哪个"。
自动播放把这个留白杀死了。所以哪怕画得再对，也只能"看到"，不能"想到"。

**错误三：数轴那个，一次犯了三个叠加的错。**
- 刻度是**符号**，不是物体。他要在"线上的位置"和"数量"之间做一次映射 ——
  这个映射对成人是免费的，对三岁是全部成本。
- 只有一个控制（往前走），没有**选择**。
- 落点是"位置"，而位置对三岁不是数量。所以他连"看得出对不对"都做不到 ——
  你也会觉得"不知道想干啥"，这是同一个问题，不是你没看懂。

**结论：数轴是 4.5~6 岁的工具。** 三岁的等价物只能是"一排能数的实物"。
把线换成点、把刻度换成球，门槛立刻消失 —— 这也是为什么下面的方案都不用线。

## 2. 判断一个形式能不能用，只看三条

| | 判据 | 不合格的样子 |
|---|---|---|
| **可控制** | 孩子的手能不能**直接**改变画面 | 只能按"下一步"、只能选给定的题 |
| **有悬念** | 有没有一个"他还不知道结果"的瞬间，且**必须停住等他押注** | 一路播到底；或者答案已经写在屏幕上 |
| **能解释** | 揭晓的**动作本身**是否展示了机制，而不只是给出答案 | 直接跳出"8"；球瞬移；数字先于物体出现 |

这三条不是并列的，是**递减的严格性**：可控制是入场券，有悬念决定他会不会投入，能解释决定他能不能学到。

## 3. 六个形式过这三条

按"三岁适配度"从高到低：

| 形式 | 可控制 | 有悬念 | 能解释 | 一句话判词 |
|---|---|---|---|---|
| **手 / 五格盘** | 强 | 强 | 强 | **5 是身体上的整体，不用数就能看穿** |
| 藏与露（盖住猜剩下） | 强 | **最强** | 强 | 遮挡是真悬念，但天然偏减法 |
| 两个盘子合并 | 强 | 弱 | 强 | 最直白，但没有"他还不知道"的时刻 |
| 十格阵 / 凑十 | 中 | 中 | 强 | 通向 100，但 10 超出三岁"一眼看穿"的范围 |
| 数轴跳跃 | 弱 | 无 | 中 | 淘汰，见上 |
| 面积 / 点阵 | 弱 | 无 | 弱 | 淘汰，乘法的前身，对加法是牛刀 |

**关键的那一行是「十格阵」为什么被排到「手」后面：**
十格阵的结构没错，错在 10。三岁的"一眼看穿"上限大约是 4~5（subitizing）。
让他相信"这一格是满的十个"，等于要求他信任一个自己没法用眼睛验证的数 —— 那就又回到抽象了。
**5 不是这样：5 是一只手。他不需要数，他看一眼就知道满了。**

---

## 4. 为什么最后选「手」

1. **5 不需要数。** 一只手就是 5，这是身体自带的度量衡。整个加法里最难的那个概念（"满"是一个整体），
   在这里变成了一个**动作**：手握起来。
2. **两只手 = 10。** 正好接上他"认得 100 以内数字"的世界，而且再往上可以自然说成"十和一"。
3. **落点是空间判断，不是数值计算。** 他要判断的是"下一颗该落在哪个空位"，
   这是三岁能做的空间推理，而不是"3+4 等于几"的符号运算。
4. **悬念来自规则，不来自隐瞒。** 满了会滑到另一只手 —— 这是真实后果，
   不是靠遮住信息骗他。所以"猜错"也不会有被骗的感觉。

## 5. 原型的规则（给家长）

打开 `tools/proto/hand-sum.html`，建议开声音。

- 屏幕上两只手，每只 **5 个位置**（四根手指 + 手心）。点任意一个空位，就会掉一颗球进去。
- **球永远落在"下一个空位"**。点对了，球直接落下；点错了，球会先在那儿停一瞬，
  再"滑"到真正的位置 —— 那一下的"咦？"就是全部的悬念。
- 一只手放满 5 颗 → **整只手变成金色**，下面出现金色的 5。这是"满"的唯一信号。
- 满了还点它 → 球会滚到另一只手去。
- 两只手都有球了，下方的圆按钮亮起来 → 按它，所有球飞出来**排成一行**，
  两组之间留一道缝（缝的左边是第一个数，右边是第二个数），然后：
  先出现数字，**再**出现算式 `3 + 2 = 5`。
- **几加几完全由他决定**：他想在左手放几个、右手放几个，就是几加几。

它其实在教三件事，一层比一层深：

1. **数量增长 = 槽被填。** 加法是"往里放"，不是"变魔术"。
2. **5 是一个整体。** 满了就握住，不是"五颗散着"。
3. **加法 = 两个部分合成一个整体，而且整体可以再数一遍验证。**
   （最后那一行球、那个数字，就是他刚才做的事的"验算"）

## 6. 可以往上加什么（按优先级）

1. **藏与露。** 盖住一只手，让他猜"下面有几颗"。这是最强的悬念，而且和现在的结构完全兼容 ——
   只需要多一块布。它也把"补数"（整体 − 一部分 = 另一部分）教了。
2. **左右手对调，总数不变。** 合并时加一个"交换"动作：两行球互换位置，数字纹丝不动。
   这是他第一次遇见"不变量"。
3. **两只手都满了 = 10。** 两个金色的手掌并在一起，然后"合十" —— 从 10 开始往 100 走。
4. **一只手 = 5，两只手 = 10，那"十再加一"呢？** 这是通往 100 以内的门，
   而且不用引入竖式，只需要"再来一只手"。

## 7. 我还没想清楚的

1. **点错只是"滑走"，这个反馈够不够？**
   我给的是"不惩罚"。但三岁可能反而需要一个更明确的"哦，不是这里"。
   这个只能看他实际反应 —— 如果他点错之后没反应，说明反馈太轻。
2. **三岁能不能稳定判断"下一个空位"？**
   如果他还做不到，就应该退一步：球自己落，他只负责在落之前**指一下**（押注），
   错了也没关系，看的次数多了自然会。这一步退让可能才是正确的起点。
3. **要不要语音？**
   整个画面里唯一的文字是最后那个算式。对他不识字的状态是合适的。
   但"三个加两个"这句念出来，可能比算式更有用 —— 也可能变成"另一个大人"。
